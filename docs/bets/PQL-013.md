# PQL-013: fake market data

Hypothesis: owned, deterministic price fixtures allow full portfolio accounting
tests to succeed independently of internet access and market-data availability.

Problem: finance tests need known prices before real provider integration.
Learning objective: isolate financial invariants from external failure modes.
Generation target: FakeMarketDataProvider, fixed-data tests and an offline test runner.
Resolution signal: complete purchase/addition/partial-sale/liquidation simulation,
per-step numeric assertions, repeated-run equality and ledger replay pass under
Docker --network none.

Constraints: existing interface, typed validated bars, no real provider, no clock,
no silent fixture repair and no backtest framework. Latest means final fixture
close; historical tests request their specific date. Unknowns outside this bet:
real calendars, retrieval coverage, historical availability and strategy performance.
